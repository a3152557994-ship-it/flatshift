## Features
- Penny-accurate Daily OT (`>8h 1.5x`, `>12h 2.0x`), Weekly OT (`>40h/wk` without double-counting), Night & Weekend Differentials, Holiday Multiplier, Unpaid Break deductions, and Gross/Net Take-Home Pay estimation.
- 1-Tap Live Shift Clock-In / Break / `+30m Break` / Clock-Out widget + 24-hour military time toggle.
- Color-coded Monthly Shift Calendar (`DAY`, `NIGHT`, `SWING`, `OT`, `PTO`, `OFF`) with daily earnings preview, true Night-Shift Dark Mode, and 1-Tap Rotation Painter (`Nurse 3×12`, `DuPont 4-Week`, `2-2-3 Panama`, `4-On 4-Off`, `Mon–Fri 8h`).
- Native vector US Letter PDF Timesheet (`UIGraphicsPDFRenderer` + live `PDFKit` preview), AirPrint, native Share Sheet, CSV Payroll Export, and local JSON Backup & Restore.
